# Immediate coding practice

All 164 HumanEval exercises include original single/team drafts exported from the actual frozen Qwen 2.5 3B benchmark artifacts. Loading these is explicitly recorded replay; test execution remains real Pyodide in a disposable worker. Code edits invalidate previous results. No model weights are downloaded.

Fresh generation is an optional server API (site/api/generate.js) using Groq's quota-limited Free Plan with openai/gpt-oss-20b (model checked 2026-10-22). It is disabled unless GROQ_API_KEY and GROQ_FREE_PLAN_CONFIRMED=true are set server-side. Limits: 12 requests/minute and 60/day per IP, 300/day per serverless instance (in-memory, best effort), ≤8,000 input characters, ≤512 output tokens, low reasoning effort; Groq's own free quota (1,000 requests/day, 8,000 tokens/minute for the account) is the hard backstop. Quota exhaustion returns 429 with no canned output or paid fallback. Agent step: the single coder or planner → coder → reviewer writes a new function, which is then automatically executed against the exercise's real HumanEval tests in Pyodide; the status line reports the model, call count and latency and whether the draft PASSED or FAILED. The model's output is never trusted on its own. Generation sends the exercise text to the provider; Python checks remain local.

Validation: TypeScript/Vite build; real Chrome loads both recorded strategies, actual Python positive/negative checks, edits clear passes, English-only/390px, no model-weight requests. See parent delivery/evidence/pairbench-immediate-browser.json. Original backend results and hardened container harness remain unchanged.
